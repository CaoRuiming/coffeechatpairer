Coffee Chat Pairer

Paste names and optional constraints from a spreadsheet, generate pairings, then copy or download the results.

How to Use

1. Paste one participant per row into People. Spreadsheet pastes with tabs are fine; the first non-empty cell on each row is used as the name.

2. Optional: paste rows into Avoid Pairing where each row lists people who should not be paired with each other in any combination. Use tabs, commas, or both. Example: Alice[TAB]Bob[TAB]Carol or Alice, Bob, Carol.

3. Optional: paste past pairings into Recent History with one pair per row. The first two non-empty cells are used. More recent rows should be lower in the box if you want them penalized more heavily.

4. Your inputs are automatically saved in this browser while you type, so an accidental reload will restore them.

5. Click Generate Pairings. If you want a different valid result, click Regenerate. If there is an odd number of people, the app warns and does not proceed.

People

One person per row.

Avoid Pairing

Each row is a group of people who should avoid each other. Tabs and commas are both accepted.

Recent History

Each row is one previous pairing. More recent rows should be lower.

Download CSV

Score meaning: lower is better. A score of 0 means no avoid rules or recent-history penalties were triggered. Higher scores mean the result had to reuse recent pairings or break avoid-pairing rules because a perfect pairing was not available.
