Coffee Chat Pairer

Paste names and optional constraints from a spreadsheet, generate pairings, then copy or download the results.

How to Use

1. Paste one participant per row into People. Spreadsheet pastes with tabs are fine; the first non-empty cell on each row is used as the name and the optional second non-empty cell is used as the location.

2. Optional: paste rows into Avoid Pairing where each row lists people who should not be paired with each other in any combination. Use tabs, commas, or both. Example: Alice[TAB]Bob[TAB]Carol or Alice, Bob, Carol.

3. Optional: paste past pairings into Recent History with one pair per row. The first two non-empty cells are used. More recent rows should be lower in the box if you want them penalized more heavily.

4. Names in Avoid Pairing and Recent History are matched to People case-insensitively. Full names, unique first names, and email addresses like john.a.doe@example.com are accepted. If any reference is ambiguous or unknown, generation stops and shows a warning.

5. Your inputs are automatically saved in this browser while you type, so an accidental reload will restore them.

6. Click Generate Pairings. Click it again any time you want a different valid result. If there is an odd number of people, the app warns and does not proceed.

People

One person per row. Optional second column: location.

Avoid Pairing

Each row is a group of people who should avoid each other. Tabs and commas are both accepted, and names are matched fuzzily against People.

Recent History

Each row is one previous pairing. More recent rows should be lower. Names are matched fuzzily against People.

Download CSV

Score meaning: lower is better. Avoid rules and recent-history matches increase the score; matching people in different non-empty locations decreases it.
